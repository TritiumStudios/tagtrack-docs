## Product Specification Sheet

The **Ewing SAM-M10Q GPS Module** is a standalone GPS module compatible with with both Betaflight and Ardupilot based paltforms. It contains both a SAM-M10Q GPS and a QMC5883L magnetometor. Together these provide accurate, real-time position and heading to enable position hold, autonamous flight and other self guided modes of flight.
