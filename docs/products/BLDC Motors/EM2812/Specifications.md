# Technical Specification

The **Ewing 2812 Brushless Motor** is a compact, lightweight outrunner engineered for efficient 6S operation in size- and weight-constrained UAS platforms. With a 900 KV wind and a 12N14P configuration, the 2812 delivers smooth torque, reliable thermal performance, and excellent efficiency when paired with 7-inch carbon fiber propellers.

---

## Key Features

- **900 KV** optimized for high-efficiency 6S operation  
- Compact **2812 stator** for lightweight propulsion systems  
- **12N14P** configuration for smooth, low-cogging operation  
- High-temperature **N35SH magnets**  
- Electrically and mechanically qualified via hipot and impulse welding tests

## Application Notes

The Ewing 2812 is well suited for smaller multirotor and fixed-wing platforms where efficiency, reduced mass, and predictable electrical behavior are critical. Adequate cooling airflow and conservative ESC timing are recommended when operating near maximum power limits.

For thrust data, integration guidance, or mission-specific configuration support, contact Ewing Aerospace engineering.
